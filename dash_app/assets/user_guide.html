scpviz Step-by-Step User Guide

This page shows real screenshots from the app and exactly which button to click at each step.

Start Import QC Preprocess Embeddings DE Enrichment Editor

1) Start the app

  1. Run python -m dash_app.app.
  2. Open http://127.0.0.1:8050.

2) Import your data

  1. Go to tab 1) Import.
  2. Upload required files.
  3. Click Import dataset.

3) Run QC

  1. Open tab 2) QC.
  2. Choose metric/grouping if needed.
  3. Click Refresh QC plots.

4) Preprocess

  1. Open tab 3) Preprocess.
  2. Select normalize/impute options.
  3. Click Run preprocessing.

5) Compute embeddings

  1. Open tab 4) Embeddings + Abundance.
  2. Set classes/genes.
  3. Click Compute embeddings + plots.

6) Differential expression and volcano labels

  1. Open tab 5) Differential Expression.
  2. Set group filters.
  3. Click Run DE + volcano.
  4. Use label/style controls as needed.

7) STRING enrichment

  1. Open tab 6) STRING Enrichment.
  2. Click Run functional enrichment.
  3. Then click Load STRING SVG.

8) SVG editor and export

  1. Open tab 7) Plot Editor (or click open-editor buttons from DE/Enrichment tabs).
  2. Edit graphics and click Save Edits.
  3. Export using Download Edited SVG or the main bundle button in the app header.
